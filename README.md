# All Hours React Website

Converted from the supplied standalone HTML build into a React + Vite project.

## Run locally

```bash
npm install
npm run dev
```

## Structure
- `src/pages` contains the eight website pages.
- `src/components` contains shared navigation, footer, layout and the 24-hour spine.
- `src/styles/global.css` contains the original site styling plus minimal React helpers.

Forms preserve the original preview behaviour and show a success message locally. Connect them to a real backend/API before production. Placeholder photography/figures and contact/company details from the source remain placeholders.
